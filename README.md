# analise-vendas-globais
Este projeto consiste na ingestão, limpeza e Análise Exploratória de Dados de uma operação de e-commerce e varejo global. Utilizando Python, o objetivo foi diagnosticar a qualidade dos dados, realizar o tratamento de inconsistências sistêmicas e gerar visualizações para identificar a relação entre volume de vendas e rentabilidade por categoria.
